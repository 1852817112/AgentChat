🧠 多轮对话上下文传递

降级时自动将对话历史注入 fallback Provider——短对话全量 Q&A，长对话框要 + 最近 2 轮

📊 双策略对比

📋

短对话策略（< 4 轮）

将完整 Q&A 历史拼在 prompt 前面，fallback 模型看到整个对话。每个回答截断到 800 字符。

⚡ 触发条件：轮数 < 4 且总字符数 < 3000
🗜️

长对话策略（≥ 4 轮）

异步调用 Kimi 生成 150 字摘要存入 .json。fallback 时注入「摘要 + 最近 2 轮原文」。

🔥 触发条件：轮数 ≥ 4 → 自动标记待摘要 → fire-and-forget 调用 Kimi

🔄 数据流

用户输入 → demo_server → getContext(sessionId)
                            │
                 ┌──────────┴──────────┐
                 ▼                     ▼
          短对话 (<4轮)           长对话 (≥4轮)
         完整 Q&A 注入           摘要 + 最近2轮注入
                 │                     │
                 └──────────┬──────────┘
                            ▼
              prompt = "[背景...]" + 当前问题
                            │
                            ▼
            AgentChat-OneWeb → 8 Provider 降级链
                            │
                            ▼
                  addTurn(sid, Q, A) → 保存到 .json
                            │
              (≥4轮) → generateSummary(sid) → Kimi 异步总结
